How it works

The browser's Geolocation API receives location fixes from available device services (GPS, Wi‑Fi, or cellular positioning depending on device/browser). JavaScript updates an interactive Leaflet map, the most recent location marker, its approximate accuracy circle, and a route polyline. The route distance is computed using the Haversine formula and filters out small location fluctuations; it is an estimate, not a surveyed distance.

GIS features: interactive pan/zoom, spatial points, polyline route, radius buffer, distance analysis, CSV export and GeoJSON export. Coordinates stay in this open page's memory until Reset/Close; export happens only when you click it.
