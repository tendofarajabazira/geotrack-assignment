About the system

Positioning: The browser Geolocation API may use GPS, Wi-Fi or cellular positioning. Continuous tracking is designed for an open, foreground tab and requires HTTPS and permission.

GIS processing: Leaflet displays position markers, movement paths, an estimated accuracy radius and a configurable geofence. Users may place the geofence centre with a map click. Distance uses the Haversine formula with basic jitter filtering. Accuracy and geofence assessment are estimates, not guarantees.

Data: Export positions to CSV or GeoJSON for analysis in QGIS. No user account, remote tracking, or background tracking is provided by this prototype.
